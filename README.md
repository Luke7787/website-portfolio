# Luke Zhuang's [Personal Portfolio](https://lukezhuang.onrender.com)

**Live Site:** https://lukezhuang.onrender.com

Welcome to my personal portfolio website. Here, you can learn more about my background and explore featured projects I’ve built. My contact information and resume are available here. The website is fully responsive for both mobile and desktop devices.

| Section   | Description |
|------------|------------|
| **Home** | Home section introducing my name with a text scramble effect, name reveal, and Vanta.js birds animation. |
| **About** | Highlights my background, experiences, and interests, along with a photo and video slideshow. |
| **Projects** | Showcases technical projects, along with project descriptions, photos, and links to GitHub and live demos. |
| **Skills** | Showcases my technical skills across programming languages, tools, infrastructure. |
| **Contact** | Shows the best ways to get in touch, with email and social links. |

## Tech Stack

- **Framework:** Next.js 
- **Frontend:** React  
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployed** Render
