# Luke Zhuang — Portfolio

A modern personal portfolio built with **Next.js** and **React**, featuring a dark theme, smooth navigation, interactive animations, and multimedia project showcases.

---

## Sections

| Section   | Description |
|------------|------------|
| **About** | Professional biography highlighting my background, experience, and interests. Includes an integrated image & video slideshow with captions and smooth arrow navigation. |
| **Projects** | Featured full-stack and systems projects with detailed descriptions, interactive slideshows, and links to live demos and GitHub repositories. |
| **Skills** | Technical expertise displayed in a structured 3-column grid: Programming Languages, Infrastructure & Tools, and Professional Skills. |
| **Contact** | Let’s Connect section with email and social links, enhanced with interactive animated background effects. |

---

## Highlights

### Interactive Vanta.js Bird Animation  
Three.js-powered animated bird background triggered on hover/tap in the Home and Contact sections.

### Custom Text Effects  
Text scramble animation for the intro line and animated name reveal in the hero section.

### Multimedia Slideshow  
Image and video gallery with smooth transitions, arrow navigation, and contextual captions.

### Project Showcases  
Each featured project includes:
- Concise technical description  
- Live Demo link  
- GitHub repository link  

### Clean Navigation Experience  
Smooth section scrolling without hash fragments in the URL. Refreshing always loads the base route.

### Responsive Design  
Mobile-friendly layout with adaptive navigation and flexible grid structures.

---

## Tech Stack

- **Framework:** Next.js (App Router)  
- **Frontend:** React 19  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  
- **3D & Effects:** Three.js, Vanta.js (Birds)  
- **Icons:** Font Awesome  
- **Image Optimization:** Next.js Image component  

---

## Getting Started

```bash
npm install
npm run dev
```

Open:

```
http://localhost:3000
```

Edit `src/app/page.tsx` to begin customizing. Changes hot-reload automatically.

---

## Deployment

The application is static-friendly and can be deployed on:

- Vercel  
- Render  
- Any Node.js-compatible hosting platform  

Refer to the official Next.js deployment documentation for detailed instructions.
